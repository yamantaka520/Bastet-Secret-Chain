**Which one do I need?**

- Getting it running on a laptop or a server, and keeping it upgraded →
  **Installation**.
- Storing credentials, deciding what needs approval, reading the ledger →
  **User guide**.
- Connecting Claude Code, Codex, Gemini/Agy, a script or CI → **AI agents**.

**Keeping translations honest.** The English edition is the source; the others
are kept in step with it. If an edition disagrees with the software, the
software is right and the manual is a bug — please open an issue saying which
language and which section.
